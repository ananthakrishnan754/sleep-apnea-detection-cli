# Sleep Apnea Detection - CLI Prototype (First)

This is the CLI-first prototype. Run module by module from terminal to demo.

## Quick Start
```bash
pip install -r requirements.txt
python cli/calibrate_user.py --user demo --hr_csv data/watch_sim/demo_hr.csv
python cli/run_demo.py --mode watch_sim --record a01 --user demo
```
